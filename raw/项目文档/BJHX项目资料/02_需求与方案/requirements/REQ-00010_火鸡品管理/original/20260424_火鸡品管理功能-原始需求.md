火鸡品管理功能

## 名词解释

药量：单件/单个火鸡品的标准计量数值，为系统基础固定参数，由管理员统一维护配置。

单个药量：绑定指定令号、火鸡品类型的单件标准药量，操作员选择对应令号及火鸡品后系统自动带出，不可手动编辑。

当量：火鸡品存储管控核心计量单位，用于约束库房、厂房最大存储容量，判定是否超量存放。

总当量：单次入库/出库操作的火鸡品合计计量值，由单个药量乘以操作数量自动计算生成。

厂房最大当量：各厂房预设的火鸡品最高存储上限，为厂房库存管控、超量预警的基准参数。

厂房结余当量：厂房当前实时剩余可存储当量，用于反映库房库存余量，作为超当量判断依据。

## 一、出入库管理-入库模块

入库新增条目默认置顶展示，所有历史已归档入库条目仅可查看，禁止修改、编辑。

当库房或厂房火鸡品存储超出最大当量上限时，系统自动触发实时报警提示。

入库时间由系统自动生成，时间精度保留至分钟。

令号：由操作员在入库界面下拉选择。

产品编号：由操作员在入库界面手动自定义输入，多品类产品支持分条分行录入。

火鸡品：由操作员在入库界面选择。

单个药量：选择对应令号、火鸡品后，系统自动读取预设参数带出，无需手动填写。

操作总当量：系统根据单个药量与操作数量，自动核算本次入库总火鸡品当量。

经办人：由操作员在入库界面选择。

厂房结余当量：根据厂房最大当量，结合历次转入、转出数据自动核算；

计算公式：厂房结余当量 = 厂房当前已存当量 +本次转入/-转出总计当量；

 

入库按钮：操作员核对所有数据无误后，点击入库按钮，完成本条数据录入归档。

## 二、出入库管理-出库模块

支持多条件检索库存，检索条件包含：库房/厂房、入库时间段、令号、产品编号、火鸡品、经办人、备注；检索完成后可对目标条目执行出库操作。

库房/厂房：操作员在出库界面选择。

入库时间：支持时间段筛选，条件为非必选，未选择则不做时间过滤。

令号：出库查询界面选择，支持模糊查询。

产品编号：筛选数据后进行勾选选择，仅支持单选。

火鸡品：选定厂房、令号后，系统加载对应已入库存储的火鸡品条目供选择。

经办人：出库界面选择。

备注：支持备注内容模糊筛选。

所有查询条件为非必选，未勾选/未填写的条件，默认不参与数据匹配筛选。

出库数量绑定对应产品编号，选定产品后录入出库数量。

本次出库总当量：系统根据入库预设单个药量及出库数量，自动计算本次出库火鸡品总当量。

经办人：支持界面选择或手动自定义输入。

厂房结余当量：实时自动计算，核算规则与入库统一；

计算公式：厂房结余当量 = 厂房最大当量 − 本次转入/转出总计当量；转入为正、转出为负。备注栏：操作员可填写本次转出产品详情、异常情况及特殊说明。

出库按钮：操作人员确认数据无误后，点击出库确认按钮，完成出库数据录入归档。

## 三、管理员模块-基础信息管理

管理员负责系统基础参数与基础资料预制维护，权限独立，普通操作员无修改权限。

令号管理：支持令号新增、删除，仅管理员维护，前端操作员禁止自定义新增及修改。

火鸡品管理：支持新增、删除，与令号进行关联绑定；操作员选择指定令号后，仅展示该令号关联的火鸡品。

单个药量管理：支持新增、删除，绑定令号+火鸡品双重关联；前端选定令号、火鸡品之后，自动生成对应火鸡品当量。（什么规则）

库房/厂房管理：支持新增、删除，同步维护各库房、厂房的最大允许存储当量；操作员仅可下拉选择，不可编辑。

经办人管理：支持新增、删除，与库房/厂房关联绑定；操作员选定对应库房/厂房后，仅展示本库/厂关联经办人。

## 四、查询员模块

### 查询员模块信息管理

查询员模块支持查看录入历史记录，修改/删除数据，并实现火鸡品当量统计、数据导出等功能。

实时看板

实时生成各厂房火鸡品存储量占比图，当存储量超过95%时，自动触发当量饱和预警。

火鸡品流转统计

支持按筛选条件及出库信息进行查询，生成各类火鸡品入库、出库记录及存储时长报表；

可展示各厂房当前存储火鸡品种类统计表、各厂房火鸡品存储量柱状图、结余当量饼状图等可视化统计。

具备对业务数据进行修改、删除操作的权限。

支持将查询结果数据导出使用。

### 二、日志及追溯信息管理

1.操作日志自动记录

系统对所有操作自动记录，包含操作人员、操作内容、操作时间、操作终端及结果。

2.追溯查询

支持按条件进行日志查询，可完整追溯每一笔火鸡品的流转去向。

3.日志安全管理

操作日志长期保存，日志数据不可删除、不可修改，确保可追溯、可审计。

与产品最大的区别，一是没库位，而是入库申请单、出库申请单；

### 表格 10

| 项           | 建议公式/规则                                  | 说明                       | 备注 |
| ------------ | ---------------------------------------------- | -------------------------- | ---- |
| 单次总当量   | 总当量 = 单个药量 × 操作数量                   | 入库、出库统一适用         |      |
| 当前库存当量 | 当前库存当量 = 历史入库总当量 − 历史出库总当量 | 反映当前实际已存量         |      |
| 厂房结余当量 | 厂房结余当量 = 厂房最大当量 − 当前库存当量     | 反映还可存多少             |      |
| 超量判断     | 当当前库存当量 > 厂房最大当量时触发超量报警    | 可阻断入库或仅预警，需确认 |      |
| 饱和预警     | 当当前库存当量 / 厂房最大当量 ≥ 95% 时触发预警 | 用于看板提醒               |      |
| 出库校验     | 出库数量不得大于当前可出库数量                 | 防止库存为负               |      |
