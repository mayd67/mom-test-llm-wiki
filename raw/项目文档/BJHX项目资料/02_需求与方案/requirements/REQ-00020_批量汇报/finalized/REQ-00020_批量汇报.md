# REQ-00020 批量汇报

## 1. 需求概述

### 1.1 业务背景

为提升车间工序汇报效率，减少操作人员逐条汇报的重复操作，MOM系统需在现有工序汇报模块中新增批量汇报能力，支持对满足条件的多条工序一次性完成汇报。

### 1.2 适用范围

| 项目 | 说明 |
| ---- | ---- |
| 适用系统 | MOM系统 |
| 适用模块 | 工序汇报 |
| 适用组织 | HX总装、电装生产车间 |
| 组织编码 | ZZCJ、DZCJ |
| 使用限制 | 仅组织范围内人员可见和使用，其他车间人员不可见 |

### 1.3 用户角色

| 角色 | 职责 |
| ---- | ---- |
| 生产操作工 | 发起横向批量汇报、纵向批量汇报，查看汇报结果并处理失败工序 |
| 系统管理员 | 配置功能权限，协助处理异常数据 |

### 1.4 本期范围

本期在现有工序报工模块中新增两类批量汇报模式，并同步补充单个报工的汇报前校验规则：

1. 横向批量汇报：对同一生产订单、同一工序号、已开工的多条工序进行批量汇报。
2. 纵向批量汇报：对当前任务中当前工序之后、且未送检/未完工的后续工序进行批量汇报。
3. 批量报工都是按合格

本期不包含批量汇报回退和批量汇报中断恢复流程。

## 2. 业务流程

### 2.1 横向批量汇报

1. 用户在工序列表中选中一条制造工序，点击“横向批量汇报”。
2. 系统自动筛选当前用户可操作范围内，满足以下条件的工序：
   - 同生产订单
   - 同工序号
   - 生命周期状态为已开工
3. 系统以列表展示筛选结果，用户可进行全选、反选、单选。
4. 用户点击“批量汇报提交”。
5. 系统对选中工序逐条执行汇报前校验，校验规则见“3.4 汇报前校验规则”。
6. 校验通过后，系统完成批量汇报，更新工序状态，实际执行人默认为当前提交人。
7. 系统展示汇报结果，区分成功和失败工序，并展示失败原因。

### 2.2 纵向批量汇报

1. 用户在工序列表中选中一条具体工序，点击“纵向批量汇报”。
2. 系统筛选该生产任务中工序号大于当前工序、且生命周期状态未送检/未完工的后续工序，并按工序号升序展示。
3. 系统默认全选后续工序，用户可取消勾选部分工序。
4. 用户点击“批量汇报提交”。
5. 系统按工序顺序执行汇报前校验，校验规则见“3.4 汇报前校验规则”。
6. 校验通过后，系统按工序顺序完成批量汇报，更新工序状态，实际执行人默认为当前提交人。
7. 如遇到检验或专检工序，该工序及其后续工序不执行一键汇报，并提示用户单独处理。

## 3. 功能需求

### 3.1 功能入口

| 编号 | 功能 | 需求说明 | 验收标准 |
| ---- | ---- | -------- | -------- |
| REQ-00020-01 | 横向批量汇报入口 | 在工序汇报模块增加“横向批量汇报”按钮 | 组织编码ZZCJ、DZCJ范围内且具备横向批量汇报权限的用户可见；无权限或非适用组织用户不可见 |
| REQ-00020-02 | 纵向批量汇报入口 | 在工序汇报模块增加“纵向批量汇报”按钮 | 组织编码ZZCJ、DZCJ范围内且具备纵向批量汇报权限的用户可见；无权限或非适用组织用户不可见 |

### 3.2 工序筛选

| 编号 | 功能 | 需求说明 | 验收标准 |
| ---- | ---- | -------- | -------- |
| REQ-00020-03 | 横向工序筛选 | 根据当前选中工序，自动筛选同生产订单、同工序号、已开工的工序 | 筛选结果准确，无漏筛、错筛；不提供人工修改筛选条件入口 |
| REQ-00020-04 | 纵向工序筛选 | 根据当前选中工序，自动筛选同一生产任务下工序号大于当前工序、且未送检/未完工的后续工序 | 仅展示后续工序，不展示当前工序及前置工序；不展示已送检或已完工工序；按工序号升序排列 |

### 3.3 工序列表与勾选

| 编号 | 功能 | 需求说明 | 验收标准 |
| ---- | ---- | -------- | -------- |
| REQ-00020-05 | 工序列表展示 | 批量汇报弹窗展示可汇报工序列表 | 列表至少展示任务编码、WBS号/令号/产品编号、物料名称、工序号和工序名称、工序内容、设备名称、汇报数量、计划开始时间、计划结束时间 |
| REQ-00020-06 | 工序勾选 | 用户可选择需要批量汇报的工序 | 支持全选、反选、单选；纵向批量汇报默认全选后续工序 |

### 3.4 汇报前校验规则

工序报工提交前，系统需执行准入校验。该规则同时适用于单个报工和批量汇报。校验未通过的工序不得执行汇报，并需向用户返回明确原因。

| 校验项 | 适用范围 | 校验规则 | 失败处理 |
| ------ | -------- | -------- | -------- |
| 物料装入校验 | 单个报工、横向批量汇报、纵向批量汇报 | 工序所需子物料必须已完成装配/装入 | 阻止该工序汇报，提示当前制造任务仍有物料待装入 |
| 拍照/附件校验 | 单个报工、横向批量汇报、纵向批量汇报 | 若工艺路线工序启用多媒体控制，则已上传照片数量必须大于等于最小拍照张数 | 阻止该工序汇报，提示需按要求拍照并上传 |
| 上道工序校验 | 单个报工、横向批量汇报 | 上道工序必须已完工 | 阻止该工序汇报，提示“选中数据有上道工序未完工，不能汇报” |
| 检验工序校验 | 纵向批量汇报 | 遇到工序名称为“检验”或“专检”的工序时，该工序及其后续工序不支持一键汇报 | 停止后续工序批量汇报，提示检验类工序需单独处理 |
| 生命周期状态校验 | 单个报工、横向批量汇报、纵向批量汇报 | 已送检、已完工等不允许重复汇报的工序不得参与报工 | 阻止该工序汇报；批量场景下不纳入筛选结果，若提交时状态已变化，则阻止该工序汇报 |

### 3.5 批量提交

| 编号 | 功能 | 需求说明 | 验收标准 |
| ---- | ---- | -------- | -------- |
| REQ-00020-07 | 批量提交 | 用户确认后点击“批量汇报提交”，系统批量执行工序汇报 | 提交后按选中工序执行汇报，实际执行人默认为当前提交人；校验未通过的工序不得汇报 |
| REQ-00020-08 | 物料装入校验 | 汇报前校验工序所需子物料是否已完成装入 | 存在未装入物料时阻止汇报，并提示对应任务仍有物料待装入 |
| REQ-00020-09 | 拍照附件校验 | 对启用多媒体控制的工序，校验上传照片数量是否满足最小拍照张数 | 照片数量不足时阻止汇报，并提示需补充拍照上传 |
| REQ-00020-10 | 上道工序校验 | 横向批量汇报时校验上道工序是否已完工 | 上道工序未完工时阻止对应工序汇报，并提示“选中数据有上道工序未完工，不能汇报” |
| REQ-00020-11 | 检验工序处理 | 纵向批量汇报遇到检验或专检工序时，不执行该工序及其后续工序的一键汇报 | 系统明确提示检验类工序需单独处理；检验或专检工序之前的可汇报工序可正常执行 |
| REQ-00020-12 | 纵向失败停止 | 纵向批量汇报按工序顺序执行，遇到校验失败或汇报失败时停止后续工序处理 | 失败工序及其后续工序不继续汇报，系统展示失败原因 |

### 3.6 结果反馈

| 编号 | 功能 | 需求说明 | 验收标准 |
| ---- | ---- | -------- | -------- |
| REQ-00020-13 | 汇报结果展示 | 批量汇报完成后展示处理结果 | 区分成功工序和失败工序，失败工序展示具体失败原因 |
| REQ-00020-14 | 失败工序处理 | 对失败工序支持用户修正后重新提交 | 失败工序可单独重新提交，不影响已成功汇报工序 |

## 4. 非功能需求

| 类型 | 需求说明 |
| ---- | -------- |
| 性能 | 单次批量汇报支持不少于50条工序，最大支持500条工序；50条以内处理时间不超过3秒 |
| 并发 | 支持不少于10人同时发起批量汇报，系统不得出现重复提交、状态错乱 |
| 兼容性 | 基于MOM现有工序汇报模块扩展，不影响单工序汇报、工序查询、生产统计等现有功能 |
| 交互 | 界面风格和操作方式遵循MOM现有设计规范，按钮、列表、弹窗等组件保持一致 |
| 权限 | 复用MOM现有权限模型，通过现有权限配置模块分别分配横向批量汇报权限和纵向批量汇报权限 |

## 5. 需求边界

| 项目 | 说明 |
| ---- | ---- |
| 不新增模块 | 不新增独立基础数据管理模块 |
| 不影响原功能 | 不改变现有单工序报工入口和主要交互方式，但单个报工需同步执行本章节定义的汇报前校验规则 |
| 不支持自定义筛选 | 横向、纵向批量汇报均由系统按规则自动筛选 |
| 不包含回退 | 本期不实现批量汇报回退 |
| 不包含中断恢复 | 本期不实现批量汇报中断恢复流程 |
