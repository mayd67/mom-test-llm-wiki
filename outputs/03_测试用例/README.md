# 测试用例目录说明

`outputs/03_测试用例/` 用于保存当前项目或需求的最终测试用例交付物。

这里不再保留中间过程目录，不再区分 `01_待评审 / 02_已评审 / 04_已沉淀` 这类阶段性结构。当前目录只保留最终需要交付或复查的三类产物。

## 当前目录结构

```text
03_测试用例/
├── 测试用例/
├── 评审/
├── MeterSphere导入/
└── README.md
```

## 目录用途

### 测试用例

存放最终保留的 Markdown 测试用例正文。

适用内容：

- 每个需求/模块当前保留的最新测试用例版本
- 不再继续使用的旧版草稿、过时版本应删除

### 评审

存放测试用例评审结果、补充评审结论和 review 稿。

适用内容：

- 测试用例评审问题清单
- 补充评审说明
- 可作为交付留痕的评审文档

### MeterSphere导入

存放用于 MeterSphere 导入的最终 Excel 文件。

适用内容：

- 每个需求/模块当前保留的最新导入版
- 已被新版本替代的旧导入版应删除

## 整理规则

- 同一份产物若存在多个版本，默认只保留最新版本。
- 中间过程文件、临时草稿、历史目录结构不再保留。
- 如后续需要新增测试用例产物，优先直接放入这三个目录之一，不再新增编号式中间目录。

## 命名建议

```text
需求编号-模块名称-测试用例-V1.2.md
需求编号-模块名称-测试用例评审-V1.2.md
需求编号-模块名称-测试用例-MeterSphere导入-V1.2.xlsx
```
