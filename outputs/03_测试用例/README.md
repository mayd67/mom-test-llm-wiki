# 测试用例输出目录说明

`outputs/03_测试用例/` 用于保存基于具体需求、模块或项目产出的测试用例交付物。

这里存放的是测试工作过程中的交付物，不是长期知识库页面。

## 推荐目录结构

```text
03_测试用例/
├── 01_待评审/
├── 02_已评审/
├── 03_MeterSphere导入/
├── 04_已沉淀/
└── README.md
```

说明：

- 历史文件如果仍在根目录，可以先保留，后续再按状态迁移
- 新增测试用例产物应优先按上述子目录放置

## 目录用途

### 01_待评审

存放测试用例初稿、草稿或待组内评审版本。

适用场景：

- 刚从已评审测试点生成测试用例
- 还在补步骤、预期、前置条件和覆盖范围
- 尚未形成可对外发布版本

### 02_已评审

存放评审通过、可作为正式正文留存的测试用例文档。

适用场景：

- 测试范围和粒度已确认
- 用例正文已完成校对
- 可以继续转换为导入版

### 03_MeterSphere导入

存放用于 MeterSphere 或其他测试平台导入的 Excel 文件。

适用场景：

- 需要导入系统执行
- 需要与 Markdown 正文分开管理
- 导入模板字段已按平台口径整理完成

### 04_已沉淀

存放通用样例、标准化模板化成果或可复用测试用例。

说明：

- 这里仍然属于 `outputs/`
- 真正长期稳定的共性知识，应继续提炼后进入 `wiki/`

## 命名建议

```text
需求编号-模块名称-测试用例-V1.0.md
需求编号-模块名称-测试用例-MeterSphere导入-V1.0.xlsx
```

示例：

```text
REQ-00010-火鸡品管理-测试用例-V1.0.md
REQ-00010-火鸡品管理-测试用例-MeterSphere导入-V1.0.xlsx
```
