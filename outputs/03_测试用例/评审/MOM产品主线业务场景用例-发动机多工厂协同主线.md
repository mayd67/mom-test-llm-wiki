# MOM产品主线业务场景用例-发动机多工厂协同主线

## 1. 用例基本信息

| 项目 | 内容 |
| --- | --- |
| 用例编号 | E2E-MOM-ENG-001 |
| 用例名称 | 多工厂协同计划到装配厂完工入库主线 |
| 用例类型 | 业务场景用例 / E2E |
| 优先级 | P0 |
| 适用阶段 | 联调、系统测试、UAT |
| 覆盖目标 | 验证厂际协同计划、生产订单、制造订单、制造任务、检验任务、工时分配、完工入库的主线闭环 |

## 2. 场景说明

本用例验证“发动机总成”在多工厂协同场景下，从协同计划生成总生产订单、展开为各分厂子生产订单、到装配厂执行装配制造、检验、工时分配、完工入库的完整主线。

本场景中：

- `10-机加厂`、`20-盘轴厂`、`30-叶片厂` 重点验证协同展开成功。
- `40-装配厂` 重点验证执行链路闭环。
- 厂际协同计划总数量为 `10`，本场景只验证装配厂子生产订单本次释放 `5` 的执行闭环。

### 2.1 本次优化依据

本用例已结合《DNW30300-计划管理》中的流程图、功能描述和业务规则进行优化，重点吸收以下内容：

- 生产订单释放后，界面应支持“确定并打开制造订单”，并自动过滤显示刚刚释放的制造订单。
- 制造订单生成批次号/序列号时，需校验“已发布且未生成过”，并按物料是否启用批次/序列号管理决定生成逻辑。
- 制造订单发布时，需要基于工艺路线进行工艺展开，自动生成制造任务，并校验工艺路线、产出比、执行标记等前提。
- 制造任务派工、开工、报工、文件浏览等步骤，需按需求文档中定义的页面行为和校验逻辑编写。
- 装配厂制造任务报工与检验任务报检，统一按工厂级汇报项配置 `合格 / 报废 / 待定` 执行。

## 6. 备注

- 本用例聚焦“装配厂执行闭环”，机加厂、盘轴厂、叶片厂在本场景中主要验证协同展开成功。
- `DNW30300` 中对“制造订单释放后自动展开”和“制造订单手工点击订单发布后展开”存在并行口径；本用例保留“订单发布”动作，便于兼容当前产品页面和用户主线操作习惯。
- 批次号/序列号样例已按需求文档中的编码示例调整为 `BT年月日+4位流水`、`SN年月日+4位流水`。
