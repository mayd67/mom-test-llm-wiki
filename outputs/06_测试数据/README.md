# 测试数据产物目录说明

`outputs/06_测试数据/` 专门保存测试数据相关产物，避免与测试执行记录、用户手册或其他交付物混放。

## 推荐结构

```text
outputs/06_测试数据/
└── 场景名称/
    ├── *_seed.json
    ├── *_import/
    ├── *_import.zip
    └── 说明文件.md
```

## 当前约定

- 一个业务场景一个子目录，例如 `大疆无人机/`
- `*_seed.json` 保存可复用的种子数据
- `*_import/` 保存展开后的系统导入文件
- `*_import.zip` 保存便于交付的压缩包
- 如有特殊字段映射、单位归一或导入注意事项，补充到场景说明文件
