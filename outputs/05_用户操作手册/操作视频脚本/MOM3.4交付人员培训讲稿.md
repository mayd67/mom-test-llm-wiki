# MOM3.4 交付人员培训讲稿

## 1. 文档信息

| 字段 | 内容 |
| --- | --- |
| 主题 | MOM3.4 产品交付培训 |
| 面向对象 | 交付经理、实施顾问、业务顾问、关键用户培训讲师 |
| 讲解目标 | 让交付人员讲清楚“怎么配、怎么演示、怎么串主线、怎么解释业务闭环” |

## 2. 培训目标

本次培训重点不是把每个按钮逐个念一遍，而是帮助交付人员掌握三件事。

1. 明白 MOM3.4 的上线顺序，知道哪些配置必须先做，哪些业务必须按前后依赖来演示。
2. 能围绕一条完整主线，把配置中心、计划、制造执行、仓储协同、质量闭环讲清楚。
3. 能在客户培训或项目交付场景下，解释每个功能的业务价值，而不是只演示系统动作。

## 3. 培训开场话术

各位同事大家好，今天这场培训的目标，是帮助大家从交付视角理解 MOM3.4 的标准实施主线。  
我们今天不单独拆散讲模块，而是按“先配置、再计划、后执行、最后质量闭环”的顺序来讲。  
大家在后续做客户培训时，也建议尽量沿用这个思路，因为客户真正关心的不是菜单本身，而是系统能不能把业务串起来。  
今天重点会覆盖四大部分：第一部分是配置中心和初始化；第二部分是计划协同和订单准备；第三部分是制造执行与仓储协同；第四部分是质量执行与不合格闭环。  
大家听完之后，要能回答客户三个问题：第一，系统上线前先配什么；第二，一张订单怎么从计划走到现场；第三，出现质量问题之后怎么闭环。

## 4. 第一部分：配置中心与初始化

### 4.1 先讲为什么要从配置中心开始

交付项目里最常见的问题，不是功能不会点，而是基础配置顺序错了。  
所以我们第一部分一定先讲配置中心。  
配置中心是超级管理员的统一入口，用来完成系统初始化和后续维护。  
建议统一告诉客户，配置中心不是“可有可无的快捷入口”，而是实施阶段的标准工作台。

### 4.2 配置中心讲解话术

请大家先进入右上角下拉菜单中的 `配置中心`。  
MOM3.4 配置中心按五大类组织：系统配置、安全配置、工厂资源、产品与工艺、个性化配置。  
其中安全配置和工厂资源是上线前必配项。  
交付时一定要反复强调一个顺序：组织和用户先于角色权限，资源主数据先于产品工艺，产品工艺先于生产执行。

### 4.3 一键导入怎么讲

如果客户是新项目初始化，推荐优先用一键导入，而不是逐条手工建数据。  
一键导入分三步。

1. `Step 1 系统配置`：准备行政组织、业务组织、用户。
2. `Step 2 工厂资源`：准备供应商、设备、工装工具、工作中心、库房、库位、工序库。
3. `Step 3 产品与工艺`：准备物料、MBOM、工艺路线。

培训时建议这样说：  
“先下载模板，再按模板整理数据，再执行导入，导入完成后不要立刻说结束，一定要进入对应业务页面做抽样核对。”

### 4.4 导入后查看导入数据的话术

导入完成以后，建议至少带客户看这几类结果。

1. 系统配置导入后，查看组织、用户是否导入成功，编码是否唯一，组织层级是否正确。
2. 工厂资源导入后，查看工作中心、设备、库房库位、工序库是否可查询，是否能被后续业务引用。
3. 产品与工艺导入后，查看物料、MBOM、工艺路线是否存在，工艺路线是否能正确关联到目标物料。

这里一定要提醒交付同事，导入成功不代表数据可用。  
真正要验证的是“能不能被下游业务引用”。  
比如工作中心导入了，但派工选不到；工艺路线导入了，但制造订单展开不了；这类问题才是项目现场最常见的问题。

### 4.5 角色权限怎么讲

接下来进入 `系统管理 -> 角色权限`。  
这一段培训的关键不是教客户怎么勾每个权限点，而是要先讲清楚权限逻辑。  
角色权限决定三个层面：能看到什么菜单、能做什么功能、能操作什么范围的数据。  
建议先按岗位建立角色，比如生产计划员、班组长、操作工、检验员、仓库管理员、质量管理员。  
然后再按岗位去配置管理平台和车间工作台的权限。

培训时可以这样讲：  
“不要一开始给所有人全权限。先按岗位拆角色，再做角色授权，再用真实用户登录验证效果。这样后续客户自己接手也容易维护。”

### 4.6 业务配置怎么讲

然后进入 `系统管理 -> 业务配置`。  
这里要告诉客户，业务配置控制的是系统业务规则，不是基础主数据。  
业务配置建议先维护产品级默认配置，项目有差异时，再启用项目级配置覆盖。

重点带客户看三类配置。

1. `MES制造执行`：控制生产订单导入后是否自动发布、发布后是否自动释放、释放后是否自动展开制造订单、是否自动生成物料准备计划。
2. `计划排产配置`：控制排产按工作中心还是设备排，是否锁定结果，锁定期限是多少。
3. `质量管理配置`：维护默认不合格审理流程标识，决定待定数量是否自动进入不合格审理流程。

这部分可以直接给客户一句总结：  
“业务配置决定系统是更偏自动化，还是更偏人工确认。自动化开关越多，对基础数据完整性要求越高。”

### 4.7 资质等级怎么讲

资质等级是很多项目容易忽略，但现场派工和报工很容易卡住的基础配置。  
建议把它放在工厂资源或主数据准备环节一起讲。  
资质等级至少要说明五个字段：资质代号、资质名称、资质类型、等级序号、有效期。  
同一资质类型下，等级序号越大，表示等级越高。  
比如工序要求“中级焊工”，那么高级焊工也可以满足条件。

培训时一定要强调两层关系。

1. 工序库里配置的是“工序资质要求”。
2. 用户管理里维护的是“人员资质关系”。

系统在派工、报工、报检时，会读取有效期内且状态有效的人员资质。  
所以如果客户问“为什么某个人派不上去”，很多时候不是权限问题，而是资质关系没有配置好。

### 4.8 质量配置怎么讲

质量配置建议分成两块来讲。  
第一块是质量报告模板；第二块是过程检质量标准。  
先讲模板是用来做检查项填写的，再讲过程检标准是用来决定什么时候生成什么检验任务的。

建议这样解释：  
“质量定义配好了，制造订单工艺展开时，系统才会自动生成检验任务。质量模板解决的是检验时填什么，过程检标准解决的是什么时候检、谁来检、按什么顺序检。”

## 5. 第二部分：计划协同与订单准备

### 5.1 一级协同计划怎么讲

如果项目是多工厂协同场景，这里要先讲 `厂际协同计划`。  
一级协同计划的核心，不是本厂内部加工，而是跨工厂交付协同。  
它依赖一级工艺路线，也就是在工艺路线里先定义好各工序分别由哪个主制单位承担。  
讲解时要告诉客户：厂际协同计划管理的是企业级零部件交付协同，不是单一工厂的制造执行任务。

建议演示顺序如下。

1. 查询目标订单。
2. 展示该订单已经关联一级工艺路线。
3. 执行一级工艺展开。
4. 从厂际协同计划进入协同排产。

### 5.2 生产订单释放怎么讲

接下来进入 `计划管理 -> 生产订单管理`。  
先讲生产订单可以导入、查询、发布、齐套检查、订单释放、暂停、恢复和指定工艺路线。  
重点一定要把“发布”和“释放”区分开。

可以直接这样对客户说：  
“发布是计划域动作，表示这张订单进入计划管理；释放是执行域动作，表示这张订单开始下达到制造执行。”

再解释释放策略。

1. 经济批量策略。
2. 剩余可释放数量策略。
3. 自由分配策略。

同时提醒客户，释放后可以自动生成制造订单，也可以按配置自动生成物料准备计划。

### 5.3 制造订单怎么讲

进入 `计划管理 -> 制造订单管理` 后，这里建议重点讲五件事。

1. 齐套检查：看物料是否满足开工条件。
2. 工艺展开：把制造订单展开成制造任务。
3. 生成批次号或序列号：为追溯做准备。
4. 计划排程：把订单带入排程模块。
5. 工艺文件浏览：提前确认现场执行所需文件。

这里要提醒交付人员，齐套检查不是简单看库存，而是判断这张单能不能真正进入执行。  
客户一旦问“为什么能排程但不能开工”，很多时候根因就在齐套和备料状态没有闭环。

### 5.4 计划调度和排程怎么讲

接着进入 `APS -> 工序计划排程`。  
这一段不要上来就讲算法，而是先讲排程依赖什么。  
排程依赖资源、日历、出勤、物料、资源能力、制造任务锁定和排产方案。  
也就是说，排程结果不是凭空算出来的，而是由基础数据和方案共同决定的。

标准讲法建议是：  
“先增加待排程订单，再选排产方案，再检查排程基础数据，再执行排程计算，最后看结果并发布。”

发布结果时，要讲清楚排程结果会回写制造任务的时间和资源信息，并影响后续派工。  
如果客户现场问“为什么排完了现场还看不到任务”，要优先检查是否已经发布结果，以及结果发布到哪一类派工方式。

## 6. 第三部分：制造执行与仓储协同

### 6.1 制造任务派工怎么讲

派工是从计划走向现场执行的关键一步。  
建议在 `生产工作台 -> 班组派工` 或 `制造任务管理` 中演示。  
讲解时要强调派工不是简单把任务分给一个人，而是把时间、工作中心、设备、执行人一起落下来。

派工时建议重点说明四件事。

1. 可以单个派工，也可以批量派工。
2. 单个派工支持任务分割。
3. 派工时要看工作中心、设备、执行人是否匹配。
4. 如果启用了资质约束，要检查人员资质是否满足工序要求。

### 6.2 工作台报工怎么讲

进入 `生产工作台 -> 工序任务报工` 后，要告诉客户这就是现场执行人员最核心的操作界面。  
这里不是只做报工，而是把开工、报工、领料申请、收料确认、物料装入、质量填报、文件浏览、异常处理都串在一起。

培训时推荐按下面顺序讲。

1. 先看任务筛选。
2. 再讲开工。
3. 再讲报工。
4. 再讲物料和质量辅助动作。

### 6.3 开工怎么讲

开工的意义是正式记录任务开始执行。  
系统会校验前置工序关系，比如上道工序是否已开工或已完工。  
开工成功后，制造任务、制造订单、生产订单的状态会联动更新。  
所以开工不是孤立动作，它标志着整张订单已经真正进入现场执行阶段。

### 6.4 领料、出库、收料怎么讲

这三步建议一定串起来讲，不要拆开。

第一步，操作工在任务界面发起领料申请。  
第二步，仓库管理员进入出库管理，根据出库申请执行拣配与出库。  
第三步，现场人员做收料确认，核对实际收到的物料数量、批次号或序列号。

可以给客户这样总结：  
“领料是需求发起，出库是仓库执行，收料是现场确认。这三步做完，账、物、任务三者才真正对上。”

### 6.5 浏览工艺文件怎么讲

在正式执行前，建议演示 `文件浏览` 和 `工艺文件浏览`。  
要说明一个看似简单但非常关键的点：  
图纸和通用文档告诉操作工“做什么”，工艺文件和作业指导书告诉操作工“怎么做”。  
如果客户很重视现场规范化，这个点一定要讲出来。

### 6.6 物料装入/拆卸怎么讲

物料装入适用于装配和可追溯场景。  
它的价值不是多做一步录入，而是形成完整的装配追溯链。  
培训时要强调两类场景。

1. 有序列号装入：按具体产品序列号去装配子件。
2. 无序列号装入：按数量维度做装入记录。

拆卸通常发生在返工返修或质量问题处理场景。  
要提醒交付同事，装入和拆卸动作后续会直接影响质量履历和不合格审理的追溯链路。

### 6.7 工步报工怎么讲

如果客户工艺比较复杂，建议单独讲工步报工。  
工步报工记录的是工序内部更细粒度的执行过程，比如哪一步由谁完成、什么时间完成。  
它解决的是复杂工序下的责任追溯，而不是替代工序报工。  
所以要讲清楚：工步报工更细，工序报工更总。

## 7. 第四部分：质量执行与不合格闭环

### 7.1 检验任务怎么讲

进入 `质量管理 -> 检验任务管理`。  
先告诉客户，检验任务不是手工随便建出来的，而是制造订单工艺展开后，根据质量定义里的检验分类自动生成的。  
这样客户才能理解为什么质量配置一定要前置完成。

### 7.2 检查项填写怎么讲

用户提到的“检查项填写”，在系统里主要体现在 `质量填报`。  
建议明确告诉客户：  
质量填报是用模板记录检查项、实测值、判定结果和备注；  
报检是对数量结果做业务确认；  
这两者有关联，但不是同一个动作。

培训时可以直接说：  
“先填检查项，再做报检；检查项解决检验记录问题，报检解决数量流转问题。”

### 7.3 检验报检怎么讲

检验报检重点讲三个数量。

1. 合格数量。
2. 报废数量。
3. 待定数量。

如果本次检验可以完工，就勾选“是否完成”。  
如果对部分数量暂时无法判定，就进入待定数量。  
这里一定要给客户讲明白，待定不是丢失，也不是跳过，而是进入后续审理流程。

### 7.4 不合格审理怎么讲

进入 `质量管理 -> 不合格品管理 -> 不合格品审理单管理`。  
不合格审理的核心是把待定在制品统一拉出来评审，并给出审理结论。  
常见结论包括：合格、报废、让步接收、返工、返修。

建议培训时按这个顺序讲。

1. 审理单如何生成。
2. 如何加入流程。
3. 如何编制审理结论。
4. 如何处理不合格品。
5. 如何执行审理完成。

这里一定要补一句业务解释：  
“系统里记录的是审理结论，很多装配子件的拆卸、替换、重新装配，现场可能在线下完成，但系统必须保留结论和数量闭环。”

### 7.5 待定报检怎么讲

待定报检是质量闭环里非常关键的一步。  
它的作用不是重新检一次，而是在不合格审理完成后，把原先冻结的待定数量，按照审理结论转成最终的合格、报废、返工或返修结果。  
交付培训时要明确告诉客户，只有完成不合格审理反馈的待定数量，才能做待定报检。

如果客户问“为什么审理完成了，数量还没有彻底结掉”，就要回答：  
“因为子件装配类场景下，审理完成只是给出处理结论，真正的账面结案还需要通过待定报检或待定报工完成最终数量划分。”

## 8. 结尾总结话术

今天这场培训，我们实际上讲的是一条完整主线。  
先通过配置中心把组织、权限、资源、工艺、质量规则配起来；  
再通过生产订单、制造订单和协同计划把计划准备好；  
然后通过排程、派工、领料、出库、收料、开工、报工把现场执行跑起来；  
最后通过质量填报、报检、不合格审理和待定报检把质量闭环补完整。  
交付同事后续做客户培训时，建议不要把这些模块割裂开讲，而是尽量围绕一张订单、一条制造主线来演示，这样客户最容易听懂，也最容易建立整体认知。

## 9. 推荐演示顺序

1. 配置中心入口与五大分类。
2. 一键导入三步与导入后抽样核对。
3. 角色权限。
4. 业务配置。
5. 资质等级与质量配置。
6. 一级协同计划。
7. 生产订单导入、发布、释放。
8. 制造订单齐套、工艺展开、批次号或序列号生成。
9. 工序计划排程与结果发布。
10. 制造任务派工。
11. 生产工作台开工、报工、领料申请。
12. 仓储出库与现场收料确认。
13. 浏览工艺文件、物料装入或拆卸、工步报工。
14. 检验任务质量填报、报检。
15. 不合格审理、待定报检。

## 10. 交付培训提醒

1. 一定区分“发布”和“释放”，这是客户最容易混淆的两个动作。
2. 一定区分“质量填报”和“报检”，这是质量模块最容易讲混的两个动作。
3. 一定区分“待定数量”和“报废数量”，待定数量进入的是后续审理，不是直接作废。
4. 一定区分“工步报工”和“工序报工”，前者更细、后者更总。
5. 一定先验数据再验功能，很多现场问题本质上不是功能问题，而是基础数据和业务配置问题。
