# 测试执行输出目录说明

`outputs/04_测试执行/` 用于保存测试执行阶段的计划、记录、导出文件和报告。

## 推荐目录结构

```text
04_测试执行/
├── 01_测试计划/
├── 02_执行记录/
├── 03_缺陷导出/
├── 04_测试报告/
├── 05_回归验证/
└── README.md
```

## 目录用途

### 01_测试计划

存放测试计划、阶段安排、范围说明和资源排期。

### 02_执行记录

存放执行结果、验证留痕、过程记录和阶段跟踪文件。

### 03_缺陷导出

存放 Jira、MeterSphere 等系统的导入导出文件。

示例：

- Jira 导入 CSV
- 缺陷批量更新文件

### 04_测试报告

存放阶段测试报告、版本测试报告和结项总结。

### 05_回归验证

存放回归范围、回归记录和回归结论。

## 命名建议

```text
项目名称-交付物类型-YYYYMMDD.md
项目名称-缺陷导入-Jira-YYYYMMDD.csv
版本号-测试报告-YYYYMMDD.md
```
