## 3. 需求理解

### 3.1 目标说明

- 本需求要解决什么问题：对 HX 项目特有的火鸡品建立二级库管理闭环，重点解决当量安全管控、出入库追溯和基础参数统一维护问题。
- 面向哪些角色：管理员、操作员、查询员。
- 主要业务场景：火鸡品物料维护、标准药量维护、火鸡品库房维护、入库申请与自动入库、库存查询、出库申请与自动出库、历史单据追溯。

### 3.2 范围说明

- 本次范围：火鸡品物料标识、火鸡品标准药量、火鸡品库房最大当量与结余当量、入库申请、入库单查询、库存查询与导出、出库申请、出库单查询。
- 非本次范围：普通物料专项改造、库位级精细化管理、审批流、超量后人工放开、独立的出入库确认补录流程。

## 5. 业务规则测试点

| 编号 | 测试点 | 说明 |
| --- | --- | --- |
| BR-001 | 令号唯一 | 同一令号不允许重复维护。 |
| BR-002 | 一个令号只对应一个火鸡品物料 | 令号与火鸡品物料是一对一关系。 |
| BR-003 | 当量计算规则正确 | 当量 = 标准药量 × 数量。 |
| BR-004 | 结余当量计算规则正确 | 结余当量 = 最大当量 − 库存当量之和。 |
| BR-005 | 入库当量不得大于结余当量 | 超量时必须阻断提交。 |
| BR-006 | 出库当量不得大于库存当量 | 超量时必须阻断提交。 |
| BR-007 | 经办人默认当前登录人 | 入库/出库申请单经办人自动带出，不需手选。 |
| BR-008 | 火鸡品标识取消时执行引用校验 | 存在关联标准药量或库存时，不允许改为“否”。 |
| BR-009 | 标准药量删除时执行关联库存校验 | 已有关联库存的标准药量记录不能删除。 |
| BR-010 | 火鸡品无库位管理且校验通过后直接完成出入库 | 不需要库位选择与二次确认。 |
| BR-011 | 已归档入库单和出库单仅可查看不可修改 | 历史单据只读。 |
| BR-012 | 火鸡品标识仅在物料/库房/库存中保留 | 单据类实体通过库房关系推导，不冗余存储。 |

## 6. 异常测试点

| 编号 | 测试点 | 说明 |

| EX-005 | 出库未选择库存记录时不允许提交 | 缺少来源库存时阻断。 |
| EX-006 | 出库超量提交失败 | 系统提示库存不足或当量不足并禁止提交。 |
| EX-007 | 出库空明细提交失败 | 无明细不允许生成出库单。 |
| EX-008 | 多条明细中存在单条校验失败时失败粒度需明确验证 | 需确认整单阻断还是仅失败明细阻断。 |
| EX-009 | 历史单据已归档后不允许修改 | 非法修改应被阻断。 |
| EX-010 | 并发出入库下库存与结余当量一致性需专项验证 | 高风险场景，需关注竞争条件。 |

## 11. 测试数据准备说明

- 前置主数据：至少准备 1 个火鸡品物料、1 个非火鸡品物料、2 个库房（其中 1 个火鸡品库房）、3 条标准药量记录。
- 前置业务数据：准备可用于入库的令号、可用于出库的库存记录、已归档入库单和出库单样本。
- 特殊状态数据：接近最大当量库房、零库存记录、边界库存记录、已有关联库存的标准药量记录、已有关联标准药量的火鸡品物料。
- 权限账号准备：管理员、操作员、查询员、非授权普通账号。

## 12. 风险与待确认项

- 风险点：多明细整单提交时，失败粒度在正式需求中未完全明确，需在实现或联调时确认。
- 风险点：同一库存并发出库、同一库房并发入库时，若无锁或幂等控制，容易出现库存与结余当量不一致。
- 风险点：查询员是否具备导出权限，正式需求和原始描述之间存在口径差异。
- 待确认项：产品编号是否必填、是否有唯一性或格式规则，正式需求未完全展开。
- 待确认项：标准药量与数量的小数位、零值、负值校验口径需确认。
