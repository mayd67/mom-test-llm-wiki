# DNW35112-变更管理-备料清单变更-测试点-V1.1

## 一、需求概览

| 项目 | 内容 |
| --- | --- |
| 需求编号 | DNW35112 |
| 需求名称 | 变更管理-备料清单变更 |
| 功能模块 | 生产计划 / 变更管理 / 物料准备 / 物料装入 |
| 主要角色 | 计划员、外围系统调用方、仓库员、操作工 |
| 主要入口 | 标准备料清单变更接口 |
| 本次关注 | 备料清单变更后的差异识别、物料准备计划同步、业务状态重算、已领/已收/已装场景处理、留痕追溯 |

## 二、测试口径

- 备料清单变更采用“全量覆盖 + 下游同步 + 结果留痕”口径。
- 系统自动处理的是：当前备料清单、物料准备计划明细、物料准备计划业务状态、装入清单、变更日志/追溯记录。
- 系统不自动处理的是：领料、收料、退料、装入、拆卸、关闭出库申请单等执行动作。
- 已发生的业务事实要保留；后续通过关闭出库申请单、重新领料、退料、拆卸等业务动作保证数据准确。
- 本文输出测试点，不展开为完整测试步骤。
