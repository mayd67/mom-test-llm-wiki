# DNW35202-库存台账与库存控制-物料库存三期-测试点-V1.0

## 一、需求概览

| 项目 | 内容 |
| --- | --- |
| 功能模块 | 库存台账与库存控制 / 物料库存三期 |
| 业务目标 | 在物料主数据上维护贮存期、有效期、油封期的间隔时间；入库时写入库存当前三期；库存查询与单据明细展示库存当前三期；对当前在库库存按单一三期类型执行手工处理并保存最终确认日期。 |
| 主要角色 | 主数据维护人员、仓储业务管理员、库管员、业务处理责任人 |
| 主要入口 | 物料主数据维护、入库申请单明细、入库单明细、入库确认、库存查询/库存列表、入库申请单明细/入库单明细/出库申请单明细/出库单明细、库存三期处理弹窗 |
| 说明 | 依据 `DNW35202-库存台账与库存控制业务方案.md`、`DNW35202-库存台账与库存控制业务方案-拆分需求条目.docx`、`DNW35202-库存台账与库存控制-库存三期管理-需求规格说明书-官方导入2.docx`、`天府轻动MOM项目详细设计方案V3` 的 `3.3` 与 `4.4` 章节整理。`02-接口与数据模型文档.docx` 仅提供接口文档占位，接口口径以下述需求规格说明书中的接口表为准。 |

## 三、需求风险清单

| 编号 | 风险点 | 风险说明 | 建议确认项 |
| --- | --- | --- | --- |
| R-001 | 命中已有库存时整体覆盖风险高 | 本次入库只填写部分三期或留空时，会整体覆盖已有库存三期，容易导致历史值被清空 | 确认页面是否提供显式提示，及并发入库场景下的覆盖优先级 |
| R-002 | 单据明细展示依赖库存引用 | 单据明细展示当前三期依赖库存引用回写；若回写时机或字段设计不一致，容易出现展示缺失或串值 | 确认四类单据明细的库存引用字段名、回写时机和空值策略 |
| R-003 | 弱校验确认链路易失真 | “间隔为空按 0 天计算”“清空三期日期”都依赖前端弱校验确认，若确认标记未正确传到后端，可能出现误清空或误拦截 | 确认初始化与保存接口间的确认标记契约 |
| R-004 | `qty > 0` 当前在库口径可能存在页面差异 | 需求要求只处理和展示当前在库库存，但不同库存页面可能对“当前在库”口径定义不同 | 确认本期覆盖的库存列表页面和统一过滤条件 |
| R-005 | 物料三期间隔时间取值范围未完全定义 | 需求已明确单位为天和允许为空，但未明确是否允许负数、0、超大值或小数 | 确认前后端对范围和格式的统一校验规则 |

## 五、跨模块影响提示
