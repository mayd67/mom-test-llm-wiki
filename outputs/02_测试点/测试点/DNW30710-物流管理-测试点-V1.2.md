# DNW30710-物流管理-测试点-V1.2

## 一、需求概览

| 项目 | 内容 |
| --- | --- |
| 功能模块 | 物流管理 |
| 业务目标 | 建立位置、位置绑定、计划到料位置、领料申请、出库、制造执行与物流任务之间的统一位置口径，支撑按需人工创建物流任务并完成跨组织跟踪闭环。 |
| 主要角色 | 系统管理员、工厂计划员/生产准备人员、库房管理员、车间操作工、物流执行人、车间主管、库房主管 |
| 主要入口 | 位置管理、位置绑定配置、物料准备计划、制造订单齐套分析、制造任务领料申请、物料出库、制造执行页面、车间工作台-物流任务、仓储管理-物流任务管理 |
| 说明 | 依据 `DNW30710-物流管理.md` 与 `DNW35204-物流任务与配送管理业务方案.md` 整理；物流任务与业务动作松耦合，未明确口径按 `to confirm` 标记。 |

## 三、需求风险清单

| 编号 | 风险点 | 风险说明 | 建议确认项 |
| --- | --- | --- | --- |
| R-001 | APS 回写与出库状态存在时序竞争 | 排产回写与出库执行可能并发发生，若状态判断时机不一致，容易出现已部分出库明细被误回写 | 确认同步链路的事务边界、重试策略和幂等口径 |
| R-002 | 导入反馈规则未写清 | 需求只写“反馈成功与失败结果”，未写明混合数据是部分成功还是整批失败 | 确认导入原子性与错误行处理规则 |
| R-003 | 跨组织可见与可操作边界复杂 | 发起人、到达组织执行人、主管三类视角存在查询与处理权限差异，容易出现越权或漏权 | 确认角色与组织组合下的可见/可接收/可完成矩阵 |
| R-004 | 历史单据与空值兼容 | 首版新增到货位置字段，历史数据可能长期为空，页面和查询逻辑易漏判空分支 | 确认历史数据是否需要回填及页面空值展示口径 |
| R-005 | 简化状态模型可能掩盖异常过程 | 首版只保留待接收、已接收、已完成、已取消四种状态，部分异常场景可能缺少细粒度留痕 | 确认是否需要补充取消原因、异常关闭原因等扩展字段 |
