# 测试数据总览

本目录用于沉淀 MOM 测试数据准备相关能力，重点承接“按模板快速生成业务数据”的复用型 skill。

它和当前知识库中其他目录的关系是：

- `01_产品需求文档/`：回答“要测什么”
- `02_数据模型/`：回答“数据对象和规则是什么”
- `03_测试点/`：回答“需要覆盖哪些验证点”
- `04_测试用例/`：回答“如何形成可执行测试用例”
- `06_测试数据/`：回答“执行这些测试前，数据如何准备出来”

## 一、当前已纳入的 skill

- `skills/mom-business-data-generator/`

该 skill 当前用于根据 Excel 模板和种子 JSON，快速生成可导入 MOM 的业务数据包，覆盖：

- 系统配置
- 工厂资源
- 产品与工艺
- 生产订单

## 二、skill 内包含的主要资源

- `SKILL.md`：主说明文件，定义适用场景、默认规则和优先脚本
- `templates/`：数据导入模板
- `assets/`：种子 JSON 与预置业务场景
- `scripts/`：构建种子、生成工作簿、校验与辅助脚本
- `references/`：模板约束、场景蓝图和导入批次说明
- `tests/`：场景与脚本的自动化校验用例

## 三、建议使用路径

1. 先阅读 `skills/mom-business-data-generator/SKILL.md`
2. 如需快速上手，再阅读 `START_HERE.md`
3. 先执行场景枚举或校验命令，再执行正式生成
4. 生成完成后，将最终对外使用的数据包按项目或日期归档到 `outputs/` 对应目录

常用命令入口：

```powershell
python scripts/build_common_seed_packages.py --list
python scripts/build_common_seed_packages.py --scenario bearing_machining_standard
python scripts/generate_seed_workbooks.py --seed assets/bearing_machining_seed.json --validate-only
```

## 四、当前使用约定

- 该 skill 本体统一保存在根目录 `skills/`，wiki 仅保留能力入口页与使用说明
- skill 自带的默认输出目录仍是其本地目录下的 `output/`
- 若生成结果要作为项目交付物或测试执行输入，建议再整理到 `outputs/04_测试执行/` 下的项目目录
