# 缺陷管理总览

本目录用于沉淀 MOM 测试过程中的缺陷编制与导入能力，重点承接“将零散问题材料整理成 Jira 可导入缺陷单”的复用型 skill。

它和当前知识库中其他目录的关系是：

- `03_测试点/`：用于发现和拆解测试关注点
- `04_测试用例/`：用于形成可执行验证步骤
- `06_测试数据/`：用于准备执行测试所需的数据
- `07_缺陷管理/`：用于将执行阶段发现的问题整理成可交付缺陷单

## 一、当前已纳入的 skill

- `04_生成缺陷单skill/defect-report-generator/`

该 skill 当前用于把聊天片段、截图摘要、日志摘要和手写问题记录，整理成符合公司 Jira 模板的 KMMOM 缺陷 CSV。

## 二、skill 内包含的主要资源

- `SKILL.md`：主说明文件，定义适用场景、字段规则、输出合同和追问边界
- `references/defect-entry-checklist.md`：缺陷录入检查清单
- `references/jira-defect-rules.md`：Jira 字段与规则说明
- `references/usage-and-jira-import.md`：使用与导入说明
- `assets/jira-import-template.csv`：Jira 导入模板
- `scripts/generate_jira_csv.py`：CSV 生成脚本

## 三、建议使用路径

1. 先阅读 `04_生成缺陷单skill/defect-report-generator/SKILL.md`
2. 再查看 `references/defect-entry-checklist.md` 与 `references/jira-defect-rules.md`
3. 准备原始问题描述、步骤、现象、期望结果等素材
4. 运行脚本生成 Jira CSV
5. 审核内容后，将最终缺陷文件归档到 `outputs/04_测试执行/` 下的项目目录

常用命令入口：

```powershell
python scripts/generate_jira_csv.py --input raw_notes.txt
python scripts/generate_jira_csv.py --text "问题描述..."
```

## 四、当前使用约定

- 该 skill 已作为知识库内能力包保存，便于统一维护缺陷录入标准
- skill 默认在本地 `exports/` 目录生成 Jira CSV
- 若 CSV 已用于项目提单、评审或交付，建议再按项目和日期整理归档到 `outputs/`
