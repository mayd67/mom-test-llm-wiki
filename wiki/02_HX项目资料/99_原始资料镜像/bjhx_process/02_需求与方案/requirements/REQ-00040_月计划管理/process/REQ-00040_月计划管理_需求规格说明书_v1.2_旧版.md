### 2. 概述

#### 2.1 业务背景

生产处在日常管理过程中，需要基于已发布的零部件加工计划（生产订单）生成月计划，对生产订单进行月度维度的计划管理。当前系统缺少月计划维度的管理功能，无法支持月计划的生成、废弃、拆分、复制调整、进度跟踪以及向 SAP 系统同步数据等业务场景。

**核心角色**：

| 角色         | 职责                                                       |
| ------------ | ---------------------------------------------------------- |
| 生产处计划员 | 负责月计划的生成、编辑、废弃、拆分、复制调整操作，提交审批 |
| 审批人员     | 负责月计划的审批通过或审批取消                             |

**核心场景**：

1. 计划员查看已发布的零部件加工计划生产订单，生成对应的月计划，进入初始界面
2. 在初始界面对月计划进行编辑确认后，提交审批
3. 审批通过后月计划进入调整界面（已确认计划）；审批取消后回到初始界面，可再次编辑提交
4. 已确认计划可通过复制方式生成调整计划（修改完成日期和数量），副本进入初始界面重新审批
5. 需要细化管理时，可将一条月计划拆分为多条子月计划
6. 废弃的月计划不再参与业务统计和唯一性校验

**项目特有约束**：

- 月计划仅来源已发布的零部件加工计划生产订单，其他类型生产订单不纳入
- 生产订单变更（阶段新增/修改/删除）对月计划的影响暂不考虑

#### 2.2 目标

建立月计划管理功能，实现以下核心能力：

1. 从已发布的零部件加工计划生产订单生成月计划
2. 支持月计划的废弃、拆分和复制调整操作
3. 基于生产订单 ID（生成场景）、SAP 订单号 + 工艺阶段 + 指定完成时间（拆分/复制场景）实现唯一性校验
4. 外部累计完成数量入库后自动回写生产订单
5. 生产订单支持穿透查看关联月计划数据
6. 审批通过后预留向 SAP 发送数据的接口扩展点

#### 2.3 适用范围

- 系统模块：MES 生产管理
- 涉及数据模型：`ProdOrder`（生产订单）、`HxMonthlyPlan`（月计划，新增）、`HxSapOrderCompletion`（SAP订单完成情况明细表）、`HxProdOrderAdjustLink`（生产计划时间调整关系表）
- 涉及外部系统：SAP（接口预留）

### 3. 需求描述

#### 3.1 月计划对象生命周期状态定义

月计划在其生命周期中经历以下阶段和状态：

| 生命周期阶段 | 生命周期状态 | 说明                                       |
| ------------ | ------------ | ------------------------------------------ |
| **创建**     | 初始         | 生成后默认状态，待处理                     |
| **创建**     | 审批取消     | 审批流程以取消方式终止（涵盖撤回、驳回等） |
| **活动中**   | 审批中       | 已提交审批流程                             |
| **已发布**   | 审批通过     | 审批通过，作为已确认计划                   |
| **已废弃**   | 废弃         | 已废弃，不可恢复                           |

状态流转路径：

```
初始 ──→ 审批中 ──→ 审批通过
  │         │
  └──→ 废弃 │
            │
  审批取消 ←─┘
    │
    └──→ 废弃
```

#### 3.2 整体业务流程

```
生产订单(零部件加工计划,已发布)
    │
    ▼
月计划生成(3.3)
    │
    ▼

    │
    ▼
审批中(3.13)
    │
    ▼
审批通过 ──→ 调整界面(3.10) ──→ 复制调整 ──→ SAP同步(3.14)
    │                                       │
    ▼                                       ▼
穿透查询(3.11)                     外部累计完成数量回写(3.12)
```

#### 3.3 月计划生成与唯一校验

##### 3.3.1 功能描述

月计划数据从已发布的零部件加工计划生产订单生成。系统读取生产订单数据，自动生成月计划记录。

##### 3.3.2 数据来源

| 数据项       | 来源模型    | 来源属性                   | 说明                     |
| ------------ | ----------- | -------------------------- | ------------------------ |
| 生产订单 ID  | `ProdOrder` | `id`                       | 月计划记录的唯一来源标识 |
| SAP 订单号   | `ProdOrder` | `intergrationId`（集成id） | 关联 SAP 订单            |
| 工艺阶段     | `ProdOrder` | `stage`                    | 工艺阶段扩展属性         |
| 指定完成时间 | `ProdOrder` | `specifiedEndTime`         | 计划完成日期             |
| 计划数量     | `ProdOrder` | `plannedQty`               | 计划数量                 |
| 计划开始时间 | `ProdOrder` | `plannedStartTime`         | 计划开始日期             |
| 计划结束时间 | `ProdOrder` | `plannedEndTime`           | 计划结束日期             |

##### 3.3.3 生成规则

1. 生产订单必须处于**已发布**状态，未发布的生产订单不可生成月计划
2. 月计划数据**仅**从**零部件加工计划**类型的生产订单生成
3. 生产订单下的交付分解子表格在月计划界面中**屏蔽**，不直接展示
4. 月计划记录来源于生产订单 ID，每条月计划记录关联唯一的生产订单
5. 生成后月计划进入**初始界面**，状态为未确认

##### 3.3.4 唯一性校验

| 校验场景       | 校验维度                                        | 校验范围                 | 校验行为                                     |
| -------------- | ----------------------------------------------- | ------------------------ | -------------------------------------------- |
| **月计划生成** | **生产订单 ID**                                 | 仅校验未废弃的月计划记录 | 若该生产订单已存在未废弃的月计划，则阻止生成 |
| **月计划拆分** | SAP 订单号 + 工艺阶段 + 指定完成日期            | 仅校验未废弃的月计划记录 | 若存在相同维度的未废弃月计划，则阻止拆分     |
| **月计划复制** | SAP 订单号 + 工艺阶段 + 指定完成日期 + 计划月份 | 仅校验未废弃的月计划记录 | 若存在相同维度的未废弃月计划，则阻止复制     |

**校验颗粒度**：日期字段按天（yyyy-MM-dd）比较。

**校验优先级**：

1. 月计划生成时，优先根据生产订单 ID 判断该订单是否已存在未废弃的月计划
2. 拆分/复制时，按对应维度校验是否存在重复计划

#### 3.4 月计划废弃规则

##### 3.4.1 功能描述

月计划**不做物理删除**，通过废弃机制实现逻辑删除。废弃后的月计划不再参与唯一性校验和业务统计。

##### 3.4.2 允许废弃的状态

| 状态     | 是否允许废弃 |
| -------- | ------------ |
| 初始     | ✅ 允许       |
| 审批取消 | ✅ 允许       |
| 审批中   | ❌ 不允许     |
| 审批通过 | ❌ 不允许     |

##### 3.4.3 废弃规则

1. 废弃后月计划记录保留在数据库中，标记为废弃状态
2. 废弃后的月计划不参与唯一性校验
3. 废弃后的月计划不参与业务统计
4. **废弃不可恢复**，如需重新使用需重新生成月计划
5. 废弃操作不需要审批，直接在初始界面执行

#### 3.5 月计划拆分规则

##### 3.5.1 功能描述

支持将一条月计划拆分为多条子月计划，用于细化管理粒度。

##### 3.5.2 允许拆分的状态

| 状态     | 是否允许拆分                                 |
| -------- | -------------------------------------------- |
| 初始     | ✅ 允许                                       |
| 审批取消 | ✅ 允许                                       |
| 审批中   | ❌ 不允许                                     |
| 审批通过 | ❌ 不允许（审批通过的月计划只能通过复制调整） |

##### 3.5.3 拆分规则

1. **只允许拆一级**，不允许嵌套拆分（不允许对拆分后的子计划再次拆分）
2. 拆分通过后，**原始计划自动废弃**
3. 拆分后的新计划进入初始界面，状态为未确认，需重新审批
4. 拆分后的新计划需通过唯一性校验（SAP 订单号 + 工艺阶段 + 指定完成日期）
5. 子月计划的计划数量之和应等于原单计划数量
6. 不限制拆分条数，拆分后的多条子计划均需满足唯一性校验

#### 3.6 月计划复制/调整规则

##### 3.6.1 功能描述

审批通过的月计划支持复制操作，生成调整计划。复制不属于拆分业务活动，原计划保持不变。

##### 3.6.2 复制前提

- 仅审批通过的月计划允许复制
- 复制操作在**调整界面**执行

##### 3.6.3 复制规则

| 规则       | 说明                                                   |
| ---------- | ------------------------------------------------------ |
| 复制份数   | **只能复制一份**                                       |
| 必填项     | 复制时必须指定新的完成日期和数量                       |
| 月份限制   | **不能在同一月份计划内复制**（取结束日期所属月份判断） |
| 新计划状态 | 副本创建后进入初始界面，状态为**初始**                 |
| 副本编辑   | 副本创建后用户可自行编辑所有字段                       |
| 原计划状态 | 原审批通过计划保持不变                                 |

##### 3.6.4 复制流程

1. 用户在调整界面选择一条审批通过的月计划，点击复制
2. 系统弹出必填项：新的指定完成日期、数量
3. 系统校验：
   - 新完成日期所属月份是否与原计划相同（月份限制）
   - 是否存在相同维度的未废弃月计划（SAP 订单号 + 工艺阶段 + 指定完成日期 + 计划月份）
4. 副本创建后，用户可在初始界面自行编辑副本的所有字段，编辑完成后发起审批

#### 3.7 月份归属规则

##### 3.7.1 功能描述

月计划的月份归属采用企业自定义月度周期，非自然月。

##### 3.7.2 归属规则

| 规则     | 说明                                                   |
| -------- | ------------------------------------------------------ |
| 归属方式 | 取日期范围的**结束日期**所属月份                       |
| 示例     | 4月26日 \~ 5月25日 → **属于5月份计划**                 |
| 业务场景 | 企业自定义月度周期（如每月26日至次月25日为一个计划月） |

#### 3.8 生产订单变更规则

> **暂不考虑**：生产订单变更（阶段新增/修改/删除）对月计划的影响在本需求中暂不处理，后续版本再行规划。

**调整记录**：

- 调整后通过 `HxProdOrderAdjustLink` 记录变更前后的计划结束时间及变更原因
- 调整后更新生产订单的 `changedCompletionTime` 属性

#### 3.12 外部累计完成数量回写生产订单

##### 3.12.1 功能描述

当外部系统（SAP）的累计完成数量入库后，系统自动将累计完成数量回写到对应的生产订单。

##### 3.12.2 回写规则

1. 数据来源：`HxSapOrderCompletion` 模型中的 `totalCompletedQty`（累计完成数量）
2. 回写目标：对应生产订单（`ProdOrder`）
3. 回写时机：外部累计完成数量入库时触发
4. 需保证数据一致性，避免累计数量重复叠加
5. 回写目标属性：`ProdOrder` 新增扩展属性 `cumulativeCompletedQty`（累计完成数量）

| SAP 接口预留       | 验证审批通过后触发预留扩展点                                        |

#### 10.2 典型例子

##### 例子1：月计划生成与唯一性校验

**前置条件**：存在一条已发布的零部件加工计划生产订单，SAP 订单号为 `SAP-001`，工艺阶段为 `机加`，指定完成时间为 `2026-06-15`。

**操作步骤**：

1. 系统生成月计划，生产订单 ID = `PO-001`，SAP 订单号 = `SAP-001`，工艺阶段 = `机加`，指定完成时间 = `2026-06-15`
2. 再次尝试生成相同维度的月计划

**预期结果**：第二次生成被唯一性校验阻止，提示"已存在相同维度的月计划"

##### 例子2：废弃后重新生成

**前置条件**：同上，已存在一条月计划，状态为初始。

**操作步骤**：

1. 在初始界面废弃该月计划
2. 重新生成相同维度的月计划

**预期结果**：废弃后唯一性校验不再拦截，可成功生成新的月计划

##### 例子3：月计划拆分

**前置条件**：存在一条初始状态的月计划，计划数量 = 100。

**操作步骤**：

1. 在初始界面拆分为两条子月计划，数量分别为 60 和 40
2. 子月计划指定不同的完成时间

**预期结果**：

- 原始计划自动废弃
- 两条子月计划生成成功，进入初始界面
- 子月计划通过唯一性校验
- 子月计划不可再次拆分

##### 例子4：月计划复制调整

**前置条件**：存在一条审批通过的月计划，计划数量 = 10，完成时间 = 2026-04-26（属于5月份计划）。

**操作步骤**：

1. 在调整界面点击复制
2. 输入新的完成日期 = 2026-06-15，数量 = 5

**预期结果**：

- 原计划保持不变
- 生成副本进入初始界面，需重新审批
- 若输入完成日期仍属于5月份（如2026-05-20），则提示"不能在同一月份计划内复制"

##### 例子5：外部累计完成数量回写

**前置条件**：生产订单 `PO-001` 当前累计完成数量 = 0。

**操作步骤**：

1. 外部系统入库，累计完成数量 = 50
2. 系统接收并回写

**预期结果**：生产订单累计完成数量更新为 50，不重复叠加
