# MOM/MES 测试用例评审补充清单

仅在制造、MES、MOM 需求场景下补充读取。

## 一、对象与动作

| 对象类型 | 评审重点 |
| --- | --- |
| 主数据 | 查询、新增、编辑、删除、引用限制、共享可见性 |
| 执行单据 | 创建、提交、审批、下发、执行、关闭、作废 |
| 配置规则 | 生效范围、匹配优先级、最小可用配置、禁用态 |
| 复制/导入 | 复制范围、唯一性、未命中处理、后续是否同步 |

## 二、制造场景高频漏项

- 组织、工厂、车间、工作中心、产线、工序之间的联动。
- 数量、单位、时间、班次、日期归属、跨月/跨班边界。
- 状态流转合法路径与非法路径。
- 功能描述里写了多条系统处理逻辑，但测试用例只验证最终成功。
- 审批中只读、审批取消回退、审批通过后的后续操作限制。
- 批量操作、部分成功、部分失败、跳过逻辑。
- SAP、ERP、外部系统接口的匹配键、幂等、异常隔离。
- 废弃/作废数据是否参与唯一性校验、统计和追溯。
- 授权放开、操作留痕、异常提示是否明确到对象和字段。

## 三、评审问题提示

| 检查项 | 常见问题 |
| --- | --- |
| 系统处理逻辑 | 需求写了 1/2/3/4 条处理规则，但用例只断言“操作成功” |
| 状态类用例 | 只测 happy path，没测非法状态操作 |
| 数量类用例 | 只测正常值，没测 0、负数、超量、合计不守恒 |
| 联动类用例 | 只看页面结果，没核对回写、同步或排除口径 |
| 审批类用例 | 只测提交，没测审批取消、重复提交、只读锁定 |
| 接口类用例 | 只测成功回写，没测匹配失败、重复消息、异常隔离 |
| 追溯类用例 | 只测当前数据，没测历史记录和废弃记录可见性 |

## 四、建议结论

- 若发现是“需求基线没拆清”导致的系统性漏测，先回到测试点层修正。
- 若只是单条用例粒度、前置、预期不合格，直接在评审结果里给出局部修订建议。
