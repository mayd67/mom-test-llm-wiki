# 临时脚本与中间产物说明

本目录用于集中存放知识库整理过程中产生的临时脚本、调试脚本和中间产物，避免这些文件长期散落在仓库根目录。

## 当前内容

- `_tmp_build_wiki_from_process_specs.py`
  用于根据测试流程规程批量生成 Wiki 页面的历史一次性脚本，当前作为历史构建逻辑留存。

- `README.md`
  说明本目录中文件的用途与清理约定。

## 使用约定

- 本目录中的内容默认不视为正式维护脚本。
- 若脚本后续仍需长期复用，应整理命名、补充说明，并迁移到 `scripts/` 根目录。
- 若脚本和中间产物已无继续使用价值，可在确认无依赖后删除。
- 不建议让新的临时脚本再次散落到仓库根目录，优先放到 `scripts/_tmp/`。
